# 🏛️ Golden Brick & Trident Hills — Next.js Platform

Official modern web application for **Golden Brick Ventures** (`goldenbrick.biz`) with flagship showcases for **Trident Hills (Forest Vista & Central Vista, Panchkula)**, luxury residences (DLF The Valley Gardens), and integrated townships, seamlessly connected with the **Golden Brick CRM** ecosystem on iOS & Android.

---

## 🌟 Key Features

- **Luxury Real Estate Design System**: Styled with Tailwind CSS, custom warm champagne gold (`#C8801F`), deep imperial forest slate (`#081410`), and Shivalik evergreen palettes.
- **Flagship Enclave Showcases**:
  - **Forest Vista**: Elevated mountain ridge residential plots (250 – 500+ Sq. Yds.).
  - **Central Vista**: Monumental architectural entrance canopy and grand tree-lined avenues (200 – 450 Sq. Yds.).
- **Interactive Plot & Milestone Calculator**: Official ₹1,39,000 / Sq. Yd. pricing engine with real-time allotment vs. premium breakdown and pre-formatted 1-tap WhatsApp quotation.
- **8-Milestone Payment Assurance**: Construction-linked escrow schedule verified under Haryana RERA (HRERA-PKL-PKL-355-2022 & HRERA-PKL-PKL-782-2025).
- **Golden Brick CRM Mobile Integration**:
  - Highlights real app screens (Executive GDV & Priorities Dashboard, Enterprise Single Sign-On, Account Preferences & Cloud Sync).
  - Official download badges for both **Apple App Store (iOS)** and **Google Play Store (Android)** (`com.reos.goldenbrick`).
- **VIP Site Visit Booking**: Interactive modal with date picker and complimentary chauffeur pickup services from Chandigarh / Panchkula.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI Library**: React 18
- **Styling**: Tailwind CSS v3 & Custom CSS Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS Micro-Interactions

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17+ or v20+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Anekantjainsagar/golden-brick-website.git
cd golden-brick-website

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) (or default port) in your browser.

### Production Build

```bash
# Build for production
npm run build

# Start production server
npm run start
```
